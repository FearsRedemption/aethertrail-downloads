# AetherTrail appearance assets v1

Game appearance models for AetherTrail's bundled local renderer. AION 2 game artwork and models are copyright NCSOFT Corporation. AetherTrail is an unofficial fan companion.

The 119 set mappings and 238 male/female GLB files are from the corresponding public MetaBot set detail pages. manifest.json records each exact source page, original model URL, file size and SHA-256. No MetaBot application or viewer code is copied.

The app downloads only the selected verified model from this repository and caches it in its own app-data folder. Personal ownership, notes and character information are never included here.


Pet/mount models: 197 exact creature records, rest pose only. Copyright NCSOFT; GLB conversion by MetaBot.GG. pet_models.json records exact source pages, files, SHA-256 hashes, and unavailable entries. Downloaded on selection and rendered locally by AetherTrail.
