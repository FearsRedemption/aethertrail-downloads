# Aethertrail Windows previews

Public AION 2 companion downloads. Application source remains private.

[Download v0.8.11 preview](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.8.11-preview)

Choose Aethertrail-Windows-x64-v0.8.11-preview.zip under Assets, extract the complete archive and run Aethertrail.exe. Windows 10/11 x64; no Python or IDE required. This preview is unsigned.

Settings now separates Display, Updates, Connection, Location and Advanced. Scheduled checks show a quiet Settings dot. Startup update prompts are enabled by default: Yes downloads, verifies and restarts; No keeps the app open; Disable startup notifications only disables the launch popup. Download update & restart is also available in Settings.

See [Tester guide](TESTER_GUIDE.md) for controls, limitations and the included Test-Aethertrail.ps1 checks. SHA256SUMS.txt is included with each release. No game driver is bundled; private recordings and application source are excluded.
