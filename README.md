# AetherTrail Windows previews

[Download v0.8.15](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.8.15-preview)

Recommended: **AetherTrail-Setup-x64-v0.8.15-preview.exe**. Run Setup, choose your application folder and shortcuts, then install. Future Setup downloads remember the installed folder. The optional ZIP is for portable use and existing in-app updates. No Python or IDE is needed. This Windows 10/11 x64 preview is unsigned.

Updates clean obsolete application runtime files while retaining settings, crafting plans, timers and character data in their separate app-data folder. Setup does not force-close a running app. Windows Installed apps supports uninstall without deleting saved data.

Settings → Instructions contains a full searchable offline guide. The sidebar logo, AetherTrail name and subtitle are centered. [Full instructions](INSTRUCTIONS.md) · [Tester guide](TESTER_GUIDE.md).

AetherTrail includes its capture helper; Npcap is a separate optional Windows driver. Screen area reading works without it. Continuous player coordinates, live inventory and party sharing remain experimental or unavailable. Settings update prompts and a quiet dot are supported; installation/restart occurs only when you choose it.

Application source stays private. Public builds exclude source archives and private captures. Checksums accompany each release.
