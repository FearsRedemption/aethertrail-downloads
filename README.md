# Aethertrail test downloads

[Download v0.8.9 — Navigation stability and minimap selection](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.8.9-preview)

Download **Aethertrail-Windows-x64-v0.8.9-preview.zip**, extract the entire ZIP and run **Aethertrail.exe**. Windows 10/11 x64; no Python or IDE required. Unsigned testing preview. Existing installations can use **Settings → Updates → Download update & restart** to update in place.

Click **Start location reading** to choose the minimap terrain and its separate title on a local screenshot. Confirmed titles follow supported region and dungeon maps; entrance labels inside the minimap are excluded. Cancel keeps reading stopped. Navigation keeps its canvas size stable through status and reminder updates, and the Settings gear stays visible. Unknown dungeon titles keep the current map.

The global top-right gear opens Settings from every page. Dark is the default; Light mirrors the lavender/gold design. Automatic update checks default to every 30 minutes while the app is open. Choose preset/custom intervals or a daily local time, plus optional startup checks and notifications. Updates install only when you choose to download and restart.

Navigation, Pets, Regions, Crafting, Timers and Checklists share the redesigned companion interface. Character progress remains separate. Saved regional snapshots can be reviewed offline; saved map marks remain unverified unless supported by linked-character game evidence. Compatibility (OpenGL) rendering is available in Settings and applies after restarting.

Passive Npcap game connection can read validated Global Steam character identity and pet progress when entering the world. Confirm the first character-profile link. Exact live position, automatic feather identity and historical ownership remain unavailable; screen tracking is experimental and requires calibrated references.
