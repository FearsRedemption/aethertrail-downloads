# AetherTrail Windows previews

Public AION 2 companion downloads. Application source remains private.

[Download v0.8.14 preview](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.8.14-preview)

Fixes the normal-startup error reporting that os was not defined. Choose the Windows ZIP under Assets, extract the whole archive and run Aethertrail.exe. Windows 10/11 x64; no Python or IDE required. This preview is unsigned.

AetherTrail has an original crystal-and-trail emblem for its sidebar, Windows taskbar, executable and tray. Navigation uses a direction arrow; Regions a folded map. Navigation controls are compact and wrap for larger text, with a stable shared status row. Character progress and tracking help are in Map tools.

The capture helper is included; only the Npcap Windows driver is separate, and no Wireshark/helper app needs to run. Screen area reading works without it. Continuous network coordinates remain unverified and need game testing at home.

Updates download and restart only when chosen. See [Tester guide](TESTER_GUIDE.md) for controls, limitations and included test scripts. Checksums accompany each release; source and private captures are excluded.
