# Aethertrail test downloads

[Download the latest native UI preview — v0.5.0](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.5.0-preview)

Download **Aethertrail-Windows-x64-v0.5.0-preview.zip**, extract the whole ZIP and run **Aethertrail.exe**. Windows 10/11 x64; no Python or IDE needed. This is an unsigned test build. Anyone can download without source-repository access.

Aethertrail includes an interactive navigation map, native recipe/crafting-item catalogs, material planning, checklists, personal countdowns, a saved server schedule library, display scaling and a preview update checker. Precise navigation-arrow tracking and live inventory are still under development. Saved schedules use your confirmed intervals; no official spawn feed is connected.
