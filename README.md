# AetherTrail Windows previews

[Latest release: v0.9.4](https://github.com/FearsRedemption/aethertrail-downloads/releases/tag/v0.9.4-preview)

**[Download the Windows Setup EXE](https://github.com/FearsRedemption/aethertrail-downloads/releases/download/v0.9.4-preview/AetherTrail-Setup-x64-v0.9.4-preview.exe).** Close AetherTrail and run Setup. It remembers an existing installation folder and preserves saved settings, timers, crafting plans and character data. No ZIP extraction is required. Windows 10/11 x64; no Python or IDE is needed. The preview is unsigned.

**Version 0.9.4:** Closet now has a larger preview, vertical armor mixer and separate collection browser, with filters above the right columns. Only confirmed Owned pets are colored; Unknown and Missing pets are grayscale. Tables support resizing/reordering columns, sorting and filtering from the headers, auto-fit widths and Ctrl+C copying. Sorting preserves the record each action edits.

The renderer and reference images are bundled with AetherTrail. Selected model files download from this repository, are checksum-verified, and are cached in the app-data folder. There is no external wardrobe page or separate viewer app. Models show the game's base male/female body, not the player's customization or hairstyle. Other appearance families outside the 119 full sets may not have models. Automatic Closet/inventory decoding remains unfinished; appearance notes are manual and character-specific. Inventory/storage totals and continuous network coordinates are not yet validated; crafting quantities remain manual and screen-based positioning remains available.

AetherTrail also includes the interactive map, a searchable 207-portrait Pets gallery, 1,463 appearance records, crafting plans, material checklists, known/manual timers and supported Exploration completion observations. Live position accuracy still needs gameplay testing; party location sharing is unfinished.

**Existing installations:** Settings → Updates → Check for updates → Download update & restart. Background checks only notify you; installation/restart remains your choice. The optional ZIP supplies the verified built-in updater and portable use. Setup does not force-close a running app. Windows Installed apps supports uninstall while retaining saved data.

Settings → Instructions provides a full searchable guide. [Full instructions](INSTRUCTIONS.md) · [Tester guide](TESTER_GUIDE.md).

The interactive map uses Aion2Maps. AetherTrail includes its capture helper; Npcap is a separate optional Windows driver. Area reading and appearance browsing work without Npcap. Source links are retained for reference; ordinary collection/model browsing does not need an external database site.

Application source stays private. Public builds exclude application source archives, personal character data and private captures. Checksums accompany every release. Game artwork/models are copyright NCSOFT; original model/reference conversion sources and library licenses are documented with the app and asset manifest.
